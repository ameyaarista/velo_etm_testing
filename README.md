Arista Velo ETM Demo — Security Feature Testing Suite

A browser-based demo toolkit for showcasing and verifying the security enforcement capabilities of Arista Velo's Edge Threat Management (ETM) platform. 
The suite generates real network traffic across four security categories — App Filtering, Domain Filtering, Geo-IP Filtering, Web Filtering and IDS/IPS 
Prevention — and streams live results to a web UI, making it ideal for sales demos, proof-of-concept testing, and lab validation.
